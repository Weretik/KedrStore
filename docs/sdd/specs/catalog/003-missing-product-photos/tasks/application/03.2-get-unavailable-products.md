# TS-005 — Отримання недоступних фотографій товарів

- **ID задачі:** TS-005
- **Покриває:** SC-002, SC-003, SC-004, SC-007, SC-008, SC-009
- **Залежить від:** EN-001
- **Точні шляхи:** `src/Catalog/Catalog.Contracts/Products/GetMissingPhotos/`, `src/Catalog/Catalog.Application/Features/Products/GetMissingPhotos/`, `src/Catalog/Catalog.Application/Contracts/Persistence/ICatalogDbContext.cs`, `tests/UnitTests/Catalog/Application/GetMissingProductPhotosTests.cs`, `tests/IntegrationTests/Catalog/Persistence/MissingProductPhotoReadTests.cs`
- **Рівень тесту:** Application unit + інтеграційний для читання PostgreSQL

## Свідчення

- Цільові тести: `GetMissingProductPhotosTests` (4 тести) і `MissingProductPhotoReadTests` (2 тести).
- Команда Red й очікуваний поведінковий збій: `dotnet test tests/UnitTests/UnitTests.csproj --no-restore --filter FullyQualifiedName~GetMissingProductPhotosTests` — компіляція не пройшла, бо типів запиту/handler не існувало.
- Команда Green і результат: тести валідатора пройшли 4/4, тести читання бази даних — 2/2.
- Нотатки Refactor: handler проєктує й виконує сторінкову навігацію в базі даних, упорядковує за ID товару, застосовує фільтр запитів активних товарів і не залежить від перевірки CDN.
- Команда Regression і результат: `dotnet test KedrStore.sln --no-build --no-restore --configuration Release` — 111 пройшли, 14 пропущено, 0 збоїв.

## Обов'язковий порядок виконання

1. **Red:** додати тести handler/валідатора для включених статусів, виключених доступних/невідомих/видалених товарів, меж сторінкової навігації, порожньої сторінки, усіх наявних адміністративних полів і порядку ID.
2. **Green:** реалізувати запит, валідатор, DTO й сторінковий запит без відстеження.
3. **Refactor:** залишити проєкцію в SQL і, де практично, уникати дублювання наявного відображення адміністративного рядка.
4. **Regression:** запустити тести Application списку товарів Catalog і збереження.
5. **Evidence:** записати цільові й регресійні результати.

## Контрольна точка

Сценарій повертає з PostgreSQL лише активні товари з недоступними фотографіями,
надає обмежені метадані перевірки й ніколи не звертається до абстракції CDN.
