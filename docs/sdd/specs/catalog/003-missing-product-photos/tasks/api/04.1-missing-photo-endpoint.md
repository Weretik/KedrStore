# TS-006 — OpenAPI-контракт і endpoint відсутніх фотографій

- **ID задачі:** TS-006
- **Покриває:** SC-002, SC-008, SC-009
- **Залежить від:** TS-005
- **Точні шляхи:** `docs/sdd/contracts/catalog/products.openapi.yaml`, `src/Catalog/Catalog.Api/Controllers/AdminProductsController.cs`, `tests/IntegrationTests/Catalog/Api/MissingProductPhotosApiTests.cs`, `tests/IntegrationTests/ApiContractTests.cs`
- **Рівень тесту:** інтеграційний API + контракт

## Свідчення

- Цільові тести: `MissingProductPhotosApiTests` (4), runtime `ApiContractTests` (3) і `MissingProductPhotoContractTests` (1).
- Команда Red й очікуваний поведінковий збій: `dotnet test tests/IntegrationTests/IntegrationTests.csproj --no-restore --filter FullyQualifiedName~MissingProductPhotosApiTests` — очікувався анонімний `200`, фактично отримано `401`, бо маршруту не існувало й запит обробила резервна політика авторизації.
- Команда Green і результат: тести endpoint пройшли 4/4; runtime-тести контракту — 3/3; статичний тест OpenAPI-контракту — 1/1.
- Нотатки Refactor: контролер відображає модель запиту в lower-camel на запит Application і делегує всю поведінку фільтрації та сторінкової навігації.
- Команда Regression і результат: `dotnet test KedrStore.sln --no-build --no-restore --configuration Release` — 111 пройшли, 14 пропущено, 0 збоїв.

## Обов'язковий порядок виконання

1. **Red:** оновити погоджену операцію OpenAPI, додати API-тести анонімного успіху, фільтрації/порядку/схеми, порожньої сторінки й некоректної сторінкової навігації, а потім підтвердити відсутність маршруту.
2. **Green:** додати тонкий endpoint і метадані відповіді, потрібні для проходження тестів.
3. **Refactor:** зберегти наявне відображення controller/result і залишити логіку в Application.
4. **Regression:** запустити тести Catalog API та зведеного контракту.
5. **Evidence:** порівняти runtime-маршрут/схему/безпеку з OpenAPI й записати результати.

## Контрольна точка

`GET /api/admin/products/missing-photos` явно анонімний, підтримує сторінкову
навігацію й відповідає контракту; його шлях запиту не виконує роботи з CDN.
