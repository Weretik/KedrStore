# TS-003 — Обмежена перевірка фотографій через CDN

- **ID задачі:** TS-003
- **Покриває:** SC-001, SC-002, SC-003, SC-004, SC-005
- **Залежить від:** TS-001
- **Точні шляхи:** `src/Catalog/Catalog.Application/Contracts/Integrations/IProductPhotoProbe.cs`, `src/Catalog/Catalog.Application/Contracts/Integrations/ProductPhotoProbeResult.cs`, `src/Catalog/Catalog.Infrastructure/Integrations/ProductPhotos/`, `src/Catalog/Catalog.Infrastructure/DependencyInjection/`, `tests/IntegrationTests/Catalog/ProductPhotos/ProductPhotoProbeTests.cs`
- **Рівень тесту:** інтеграційний для адаптера з контрольованим HTTP handler/сервером

## Свідчення

- Цільовий тест: `ProductPhotoProbeTests` (13 тестів).
- Команда Red й очікуваний поведінковий збій: `dotnet test tests/IntegrationTests/IntegrationTests.csproj --no-restore --filter FullyQualifiedName~ProductPhotoProbeTests` — компіляція не пройшла, бо `ProductPhotoProbe` не існував.
- Команда Green і результат: та сама цільова команда — успішно 13/13.
- Нотатки Refactor: побудову запитів, перевірку перенаправлень, класифікацію й обмежену діагностику централізовано в адаптері; контракт Application не містить HTTP-типів.
- Команда Regression і результат: `dotnet test KedrStore.sln --no-build --no-restore --configuration Release` — 111 пройшли, 14 пропущено, 0 збоїв. Контрольований handler доводить, що резервний GET використовує `ResponseHeadersRead` і не читає тіло відповіді.

## Обов'язковий порядок виконання

1. **Red:** додати контрольовані HTTP-тести для зображення `2xx`, `404/410`, відповіді не із зображенням/без медіатипу, таймауту, `429/5xx`, обмежень перенаправлення й резервного шляху `405/501`; підтвердити очікувані збої.
2. **Green:** реалізувати типізований клієнт і мінімальну класифікацію для проходження тестів.
3. **Refactor:** централізувати обмежену діагностику й побудову запитів.
4. **Regression:** запустити підмножину інтеграційних тестів адаптера.
5. **Evidence:** записати тести, зокрема доказ, що резервний шлях не читає все тіло.

## Контрольна точка

Кожен клас відповіді має один детермінований результат, незалежний від транспорту;
запити залишаються на дозволеному HTTPS-хості CDN, і повне тіло зображення не завантажується.
