# Оновлення проєкції залишків

**Модуль:** catalog\
**Статус:** реалізовано\
**Відповідальні:** backend-команда\
**Створено:** 2026-07-27\
**Пов'язано:** задачі імпорту Catalog з 1C

## Мета

Як користувач каталогу, я хочу, щоб цільовий імпорт залишків оновлював модель читання списку товарів, аби фільтр і значення `InStock` залишалися актуальними.

## Межі

- У межах: перебудувати `ProductListProjections` після успішного цільового імпорту `stocks`.
- Поза межами: інкрементальне або часткове оновлення проєкції.
- Припущення: непорожня відповідь 1C щодо залишків є авторитетною для вибраного кореня.
- Залежності: `IProductListProjectionRebuilder` і наявний хост задач каталогу.

## Сценарії

1. Якщо цільовий імпорт залишків оновив залишки товарів, після його завершення проєкція списку товарів перебудовується.
2. Під час повного імпорту етапи залишків не виконують незалежної перебудови; повна задача перебудовує проєкцію один раз наприкінці.

## Контракт і сумісність

- Документ API-контракту не потрібен, оскільки API-контракт не змінюється.
- Наявні споживачі й сумісність: `stocks` тепер автоматично оновлює `InStock`; аргументи CLI не змінюються.
- Авторизація та ідемпотентність: не застосовуються до задачі CLI.
