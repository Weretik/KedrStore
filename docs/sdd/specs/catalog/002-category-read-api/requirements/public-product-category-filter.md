# Публічний список товарів — вибір піддерева категорії

**Статус:** заплановано, 2026-10-19. Поточний обробник застосовує точну рівність `CategoryId` або `CategorySlug`; це доповнення ще не реалізоване.

## Мета й межа

Сторінка батьківської категорії, наприклад `zamki-900002`, має показувати доступні на сайті товари самої категорії та всіх її дочірніх категорій, незалежно від глибини вкладеності. Правило застосовується до наявних `GET /api/catalog/{lang}/{categorySlug}/products` і `GET /api/catalog/{lang}/products?categoryId=…`. Воно не змінює дерево категорій, DTO товару, порядок сортування, доступ або інші фільтри.

## Правила

- **R-PC-01:** Якщо вибрано наявний `categorySlug` або `categoryId`, публічний список включає товари вибраної категорії та кожного її нащадка на будь-якій глибині. Сусідні гілки не включаються. Категорія без нащадків зберігає звичайну поведінку списку.
- **R-PC-02:** Вибір категорії поєднується з чинними фільтрами публічного списку, насамперед `ExportToSite`, `inStock`, пошуком, ціною, акцією та новинкою. `CategoryId` має чинний пріоритет над slug, якщо клієнт передав обидва значення.
- **R-PC-03:** Усі фільтри категорії та товару застосовуються **до** `pagedInfo.totalRecords`, сортування, `Skip` і `Take`. `totalPages` обчислюється з відфільтрованої кількості; сторінки не наповнюються товаром із чужої гілки й не пропускають товар із власної.
- **R-PC-04:** Невідомий валідний slug або ID зберігає чинну семантику порожньої сторінки `200` з `totalRecords = 0`; некоректний ввід і надалі перевіряє чинна валідація. Параметри й форма відповіді не змінюються.

## Сценарії приймання

- **SC-PC-01:** Є батьківська категорія, дитина, онук і сусідня гілка; кожна має публічний товар. Запит за slug батька повертає товари перших трьох рівнів, не повертає товар сусідньої гілки й показує правильну відфільтровану кількість.
- **SC-PC-02:** Для тих самих категорій запит за ID батька повертає той самий набір. Запит за slug листка повертає лише його товари. Якщо передані обидва селектори, застосовується ID.
- **SC-PC-03:** За `pageSize = 1` результати на послідовних сторінках охоплюють усі товари піддерева без дублікатів; `totalRecords` і `totalPages` однакові та правильні на кожній сторінці. Непублічні товари й товари, які не проходять інший активний фільтр, не враховуються.
- **SC-PC-04:** Для невідомого валідного slug або ID відповідь `200` містить порожній `value`, `pagedInfo.totalRecords = 0` і `pagedInfo.totalPages = 0` за чинною формою відповіді.
