# 002 — Архітектура тестів і перевірки delivery

- **Модуль:** Platform
- **Тип:** фіча
- **Статус:** завершено
- **Відповідальні:** Platform-команда
- **Створено:** 2026-09-09

Набір тестів реорганізовано за бізнес-модулями й рівнями тестування; конвеєр передачі перевіряє модульні, інтеграційні, PostgreSQL-специфічні та архітектурні ризики до розгортання. Ця робота змінює лише тестову інфраструктуру й перевірки, а не поведінку у продукційному середовищі чи публічні API-контракти.

## Примітки про зміни

- 2026-09-09 — Фічу завершено за локальним критерієм delivery. PostgreSQL-тест, що потребує Docker, реалізовано, він виявляється й обов'язковий у CI; його локальний пропуск є погодженим винятком середовища. Майбутній збій GitHub Actions розглядатиметься як CI-інцидент, а не як причина залишати завдання реалізації відкритим.
- 2026-09-09 — Архітектурні перевірки виявили й допомогли прибрати дві зовнішні залежності: `Identity.Api -> Identity.Infrastructure` і `BuildingBlocks.Infrastructure -> Catalog.Application`. Адаптер XML-to-JSON разом із реєстрацією перенесено до `Catalog.Infrastructure`.
- 2026-09-09 — Початкову специфікацію створено за аудитом архітектури тестів; реалізацію погоджено для всієї фічі.
