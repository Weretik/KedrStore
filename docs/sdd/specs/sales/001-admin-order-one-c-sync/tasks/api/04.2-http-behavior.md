# T120 — API: HTTP-поведінка, авторизація та ідемпотентність

**Залежить від:** T110

- [x] Створити DTO запиту/відповіді в `src/Sales/Sales.Api/Contracts/Orders/`, якщо вони відрізняються від DTO Application.
- [x] Позначити endpoint `[AllowAnonymous]` як тимчасове погоджене рішення про доступ. Додати явну production-задачу заміни на `PolicyNames.CanManageOrders`; ця політика дозволяє ролі Manager та Admin і не потребує нової ролі чи політики.
- [x] Вимагати HTTP-заголовок UUID `Idempotency-Key` і передавати його до команди створення. Тотожний повтор у межах 24-годинного зберігання повертає початковий результат `200 OK`; використання ключа з іншими даними запиту повертає `409 Conflict`.
- [x] Оголосити метадані `ProducesResponseType` для успіху, помилки валідації, відсутності авторизації, заборони, відсутнього контрагента й конфлікту ідемпотентності, де застосовно.
- [x] Підтвердити, що endpoint ніколи не повертає деталі діагностики SOAP чи сутності збереження.

## Контрольна точка

Endpoint дотримується тимчасового рішення про анонімний доступ, має явну наступну задачу щодо production-авторизації та задокументовану поведінку повторного запиту.
