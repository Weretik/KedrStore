# T010 — Domain: агрегат замовлення та позиції

**Залежить від:** T001–T006

- [x] Створено `Order` у `src/Sales/Sales.Domain/Orders/Entities/Order.cs`; він володіє технічним `Id`, незмінними `OrderNumber` і `CounterpartyId`, часовою позначкою, коментарем та приватною колекцією позицій.
- [x] Створено `OrderLine` у `src/Sales/Sales.Domain/Orders/Entities/OrderLine.cs`; він зберігає історичні `ProductId`, `ProductName`, додатну кількість і загальну суму позиції.
- [x] Створено очікувані помилки інваріантів у `src/Sales/Sales.Domain/Orders/Errors/OrderErrors.cs`.
- [x] Додано фабрики агрегату й позицій, які перевіряють дані до створення замовлення.
- [x] `CounterpartyId` та `OrderNumber` зроблено незмінними після створення; порожні позиції, пусті поля товару, недодатна кількість, від'ємна сума й некоректні номери замовлень відхиляються.

## Контрольна точка
