# T155 — задачі: зберегти номер документа 1С

**Залежить від:** T020, T050, T060, T100, T150

- [x] Додати nullable `OneCDocumentNumber` до `OneCOrderSync`. Призначати його може лише перехід агрегату в прийнятий стан із підтвердженого успішного результату `ISalesOneCWriteClient`. Після призначення значення незмінне.
- [x] Зіставити поле в `OneCOrderSyncConfiguration` як nullable-рядок довжиною до 128 символів, згенерувати нову неруйнівну EF Core-міграцію Sales і застосувати її через наявну задачу міграцій. Не змінювати вже застосовану міграцію замовлень. Застосунок використовує наявну автоматичну задачу міграцій.
- [x] У `SyncOneCOrdersJob` зберігати повернений `OneCDocumentId` разом із переходом у `Accepted`. Відсутній ідентифікатор або відповідь, що документ не створено, повинні залишити `BusinessError` і нульове значення `OneCDocumentNumber`.
- [x] Додати тести Domain, збереження й задачі, які доводять: прийнята відповідь зберігає повернений номер, шляхи помилки його не зберігають, а прийнятий номер не можна змінити подальшою обробкою.
- [x] Залишити номер доступним для майбутньої проєкції читання/стану замовлення адміністратора. Не додавати HTTP endpoint у цій задачі; маршрут і контракт є окремим рішенням API.

## Контрольна точка

Після успішного `CreateSiteRequest` той самий запис `OneCOrderSync` містить `Status = Accepted`, `AcceptedAtUtc` і номер документа 1С обмеженої довжини. Номер безпечний для майбутнього показу у frontend, а необроблена помилка SOAP не відкривається через HTTP.
