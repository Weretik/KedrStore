# T145 — задачі: сповіщення Telegram про dead-letter та експорт Excel

**Залежить від:** T010, T020, T040, T100

**Рішення (2026-09-02):** використовувати обмежені стійкі повтори в `OneCOrderSync`. Невдале сповіщення Telegram повторюється наступними запусками `sync-one-c-orders` через `5m -> 15m -> 30m -> 1h -> 3h`, максимум п'ять спроб сповіщення. Після п'ятого збою сповіщення позначається як вичерпане для спостережуваності; збережений стан замовлення `DeadLetter` не змінюється, а запит до 1С ніколи не надсилається повторно.
