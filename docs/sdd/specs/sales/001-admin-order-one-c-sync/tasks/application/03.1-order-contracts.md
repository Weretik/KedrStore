# T090 — Application: контракти замовлення

**Залежить від:** T010, T020

- [x] Створити `src/Sales/Sales.Application/Features/Orders/Create/` і визначити `CreateOrderCommand`, DTO запиту/позицій, DTO результату та валідатор. Реалізація `CreateOrderCommandHandler` належить T100.
- [x] Визначити абстракцію Application для генератора номера замовлення `SO-YYYYMMDD-NNNN` із базою даних; Application передає згенерований номер до `Order.Create`.
- [x] Додати лише потрібні Application-абстракції для пошуку контрагента, транзакційного збереження замовлення й стійкого запису синхронізації. Не допускати `SalesDbContext` до Application.
- [x] Повторно використати DTO запиту/результату `ISalesOneCWriteClient`, введені T060; вони не повинні відкривати згенеровані класи WCF.
- [x] За потреби використати наявні `IReadSalesDbContext` або `ISalesRepository<T>`; задокументувати єдиного споживача кожної нової абстракції. `IOrderNumberGenerator`, `IOrderProductReader` і `IOrderCreationStore` споживає лише `CreateOrderCommandHandler` із T100; наявний контекст читання й загальний репозиторій не можуть атомарно зберегти запис ідемпотентності, який належить Infrastructure.

## Контрольна точка

Application має явні контракти CQRS та інтеграції без залежності від Infrastructure.
