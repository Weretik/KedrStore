Наявний загальний репозиторій Ardalis підтримує збереження агрегату й запити готових записів через специфікації, тому розширення не потрібне.

## Контрольна точка

Мапінги підтримують доменну модель і забезпечують один життєвий цикл передавання на замовлення без атрибутів збереження в Domain.

Реєстрацію Catalog виправлено узгодженням `DbContextOptions<CatalogDbContext>` з singleton `IDbContextFactory<CatalogDbContext>`; тимчасову design-time-фабрику Sales видалено. Звичайний шлях EF CLI через Host.Api тепер проходить у T050.

## Запис перевірки

- `dotnet build src/Sales/Sales.Infrastructure/Sales.Infrastructure.csproj --no-restore` — пройшла з 0 помилок. Залишилися наявні попередження NU1903 про вразливості залежностей.
- `dotnet ef dbcontext info --project src/Sales/Sales.Infrastructure/Sales.Infrastructure.csproj --startup-project src/Bootstrapper/Host.Api/Host.Api.csproj --context SalesDbContext --no-build` — була заблокована до створення `SalesDbContext` раніше наявною перевіркою сервісів `Host.Api`: singleton `IDbContextFactory<CatalogDbContext>` споживає scoped `DbContextOptions<CatalogDbContext>`. Це потрібно було виправити або додати design-time-фабрику `SalesDbContext` до генерації міграції в T050.
