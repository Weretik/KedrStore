## Контрольна точка

Команди EF Core і наявний спосіб перевірки OpenAPI під час виконання зафіксовано. Оновлення бази даних явно обмежено ізольованою тестовою базою, яку надає оператор.

## Запис перевірки

- `dotnet ef --version` — успішно; версія `10.0.2`.
- `dotnet ef migrations add --help`, `has-pending-model-changes --help`, `migrations script --help` і `database update --help` — успішно; потрібні параметри підтримуються.
- Огляд репозиторію — окремого OpenAPI CLI не знайдено; тести OpenAPI під час виконання містяться в `tests/IntegrationTests/ApiContractTests.cs`.
- У цьому підетапі підготовки не виконували міграцію, оновлення бази даних, збірку чи тести; ці команди належать до завдань реалізації/перевірки.
