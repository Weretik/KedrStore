# 005 — Збережені чернетки замовлень Admin

- **Модуль:** Sales
- **Споживач:** React Admin
- **Статус:** реалізовано в коміті `b3797c1`; міграцію не застосовано, потрібна перевірка з PostgreSQL і review
- **Перевірено базис:** 2026-10-21
