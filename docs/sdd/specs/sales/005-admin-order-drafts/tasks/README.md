# Граф задач

1. **EN-001 — Контракт і міграція.** Зафіксувати OpenAPI, concurrency та idempotency, зафіксувати цілочисельну quantity та правила FK; контракт/міграційний план перевірити без запуску міграції.
2. **TS-001 — Domain/EF.** Додати Draft/DraftLine, typed IDs, конфігурації, міграцію й цільові domain/EF тести інваріантів; Red → Green → Refactor → regression/evidence.
3. **TS-002 — CRUD.** Додати handlers, read models, авторизовані endpoint-и й тести валідації, паралельного редагування, видалення та відсутності 1C sync.
4. **TS-003 — Списки.** Додати server search/filter/sort/page зі стабільною пагінацією; SQL інтеграційні тести й план запиту для ризикових умов.
5. **TS-004 — Документація/звірка.** Оновити Sales feature, DB map, OpenAPI/індекси; занести цільові перевірки й залишкові ризики.

EN-001 → TS-001 → TS-002; TS-001 → TS-003; усі → TS-004. Ціни використовують TS-001 із [004](../../004-admin-order-workspace/tasks/README.md). Не запускати міграцію чи job під час SDD.
