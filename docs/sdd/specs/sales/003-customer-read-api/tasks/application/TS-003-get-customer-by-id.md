# TS-003 — Отримати клієнта за ID контрагента

- **ID завдання:** TS-003
- **Охоплює:** SC-002, SC-003
- **Залежить від:** TS-001
- **Точні шляхи:** `src/Sales/Sales.Application/Features/Customers/GetById/`, `tests/UnitTests/Sales/Application/GetCustomerByIdQueryHandlerTests.cs`
- **Рівень тестування:** Application

## Свідчення

- **Цільовий тест:** `GetCustomerByIdQueryHandlerTests`
- **Red:** спільний запуск обробників клієнтів скомпілював 11 тестів; 2 випадки для обробника деталей не пройшли, оскільки тимчасовий обробник повернув очікувану помилку відсутньої реалізації; тести ідентифікатора й приватності пройшли.
- **Green:** спільний цільовий запуск обробників клієнтів пройшов 11/11.
- **Рефакторинг:** обробник безпосередньо делегує виклик `ICustomerReadService`, зберігає результати успіху, «не знайдено» й помилки та передає токен скасування; цільові тести залишилися Green.
- **Регресія:** `dotnet test tests/UnitTests/UnitTests.csproj --filter FullyQualifiedName~Sales.Application` пройшов 32/32.

- [x] **Red:** додати цільові випадки, що мають падати, для некоректного, невідомого й видаленого ID, помилки читання, виключення приватних даних і скасування, потрібних для SC-002/SC-003.
