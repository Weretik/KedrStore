# TS-006 — Перевірити й завершити фічу читання клієнтів

- **ID завдання:** TS-006
- **Охоплює:** SC-001, SC-002, SC-003, SC-004
- **Залежить від:** TS-005
- **Точні шляхи:** `KedrStore.sln`, `tests/UnitTests/`, `tests/IntegrationTests/`, `docs/sdd/specs/sales/003-customer-read-api/`, `docs/sdd/contracts/`
- **Рівень тестування:** регресія та завершення фічі

## Свідчення перевірки

- **Відновлення залежностей:** `dotnet restore KedrStore.sln`; пройшло, усі проєкти актуальні.
- **Збірка:** `dotnet build KedrStore.sln --no-restore`; пройшла з 0 попереджень і 0 помилок.
- **Тести:** `dotnet test KedrStore.sln --no-build` після зміни щодо анонімного доступу, з фікстурою Sales на ізольованій схемі PostgreSQL 18; модульні 70/70, архітектурні 10/10, інтеграційні 83/83, без пропусків.
- **Відоме обмеження:** Redocly видає рекомендаційне попередження `info-license` для коректного контракту фічі. Пошук, операції запису, історія, вбудовані замовлення й експорт залишаються поза погодженим обсягом.
