# Delegation contract

For every work packet record:

- source feature path and IDs;
- exact goal and authorized scope;
- allowed and forbidden paths;
- dependencies and expected inputs;
- required deliverables and evidence;
- verification commands;
- database/API safety constraints;
- Git mode: no commits unless explicitly authorized;
- return format: changed paths, commands/results, blockers, residual risks, and proposed shared-evidence updates.

The coordinator owns shared feature records, aggregate OpenAPI, integration decisions, and final verification.
